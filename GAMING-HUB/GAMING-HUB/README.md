# GAMING-HUB

Proyecto intermodular de 2º DAW.

Plataforma para gestionar tu biblioteca de videojuegos, compartir reseñas y seguir tu progreso gaming.

## Estado actual

- Pantalla de autenticación (login y registro) maquetada, con cambio entre formularios y validación básica en JavaScript.
- Página de inicio provisional.

## Estructura

```
CSS/   estilos
HTML/  páginas (index.html, login.html) e imágenes
JS/    scripts (auth.js)
```

## Cómo probarlo

Abre `HTML/index.html` en el navegador y entra desde ahí a la pantalla de autenticación.

## Tecnologías

HTML5, CSS3 y JavaScript.
